# Contributing to Vlasolver

Thank you for your interest in Vlasolver. This repository is a public snapshot (see Section 2 of the README): the maintainers are currently scoping the governance, contribution, and release processes for the project as part of building an open-source ecosystem around trustworthy kinetic plasma simulation. Until those processes are ratified, contributions are handled as follows.

## How to contribute today

- **Open an issue first.** Bug reports, questions, use cases, and feature discussions are all welcome through GitHub issues. For major changes, please open an issue to discuss what you would like to change before writing code.
- **Pull requests** are reviewed by a maintainer before merge. A second maintainer reviews any change to the build system or to a dependency.
- **Sign off your commits.** Contributors certify the origin of their contributions with the [Developer Certificate of Origin](https://developercertificate.org/) (`git commit -s`).

## Ways to contribute

- New examples (geometries, physics scenarios, test cases)
- Documentation and Python post-processing tools
- Use cases and datasets from your own runs — these directly inform the data and benchmark standards being scoped
